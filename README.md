# DiabetesPredictionMain_App

A Python-based machine learning application that uses a trained classification model to predict the likelihood of diabetes based on user-provided health data.

## Overview

This project demonstrates how a trained machine learning model can be integrated into a Python application to process user inputs and generate predictions.

The project combines **Python, machine learning, data processing, and application development**.

## Project Structure

```text
DiabetesPredictionMain_App/
│
├── Diabetes.csv
├── DiabetesPred.css
├── DiabetesPredMain_app.py
├── classifier.pkl
├── requirements.txt
└── README.md
```

### Key Files

| File                      | Description                                   |
| ------------------------- | --------------------------------------------- |
| `DiabetesPredMain_app.py` | Main Python application                       |
| `Diabetes.csv`            | Dataset used by the project                   |
| `classifier.pkl`          | Trained machine learning classification model |

## Features

* Accepts health-related input data
* Processes user input
* Uses a trained classification model
* Generates a diabetes prediction
* Provides an application interface
* Separates application logic, styling, dependencies, and model data

## Installation

Clone the repository:

```bash
git clone https://github.com/BukhosiKei/DiabetesPredictionMain_App.git
```

Navigate to the project:

```bash
cd DiabetesPredictionMain_App
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python DiabetesPredMain_app.py
```
